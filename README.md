# 리더스이사

`lineagem.kr`을 대표 URL로 설정한 한글 Astro 정적 사이트입니다.

## 출처

[ProCleaning](https://github.com/anastasiiaxfr/ProCleaning)의 MIT 라이선스 Astro 구조를 바탕으로 재구성했습니다. 라이선스 전문은 `LICENSE`에 보존했습니다. 원본의 이미지나 업체 정보는 사용하지 않았습니다.

## 실행

```bash
npm ci
npm run build
```

대표 주소 기본값은 `https://lineagem.kr`입니다. 배포 환경의 `SITE_URL` 값이 있으면 우선 사용합니다. 네이버 소유 확인 값이 발급되면 `NAVER_SITE_VERIFICATION`에 메타 태그의 `content` 값만 입력하고 다시 배포하세요.

실제 업체 연락처, 서비스 지역, 견적, 자격, 보증과 시공 실적은 제공되지 않아 임의로 적지 않았습니다. 배포 후 확인된 정보로 보강하세요. 이 도메인에 색인된 이전 게임 콘텐츠 URL은 배포 후 응답과 검색 반영을 점검해야 합니다.
